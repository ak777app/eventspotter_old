EventSpotter - spotting entities that talk about events
This repository contains the EventSpotter Java project copied from amark-india/eventspotter (source).

Included:
- src/ (Java source code)
- data/ (datasets and SQL dump)
- evaluation/, report/, paper/ and top-level build/config files

Excluded:
- lib/*.jar and lib/**/apidocs/** (too large to upload reliably via the REST API)

Original source: https://github.com/amark-india/eventspotter
